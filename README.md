# EVクイズ（○×ボディ判定）

電気自動車に関する○×クイズを、カメラに映った**体のポーズ**で答える展示ゲームです。答えが○なら**両手を頭の上でくっつける**、×なら**両腕を胸の前でクロス**。問題と解説は音声で読み上げます。

紅陵祭2026 のゲーム一覧：https://takuden-formula.github.io/koryosai2026/

```
Webカメラ → Chrome / Edge（index.html：MediaPipe Pose で骨格を読む → classify() で ○ / × を判定 → 正解・解説を表示して読み上げ）
```

- **インストール不要・オフラインで動く**：Windows は Edge（または Chrome）と Windows 標準の PowerShell、**Mac は Chrome（または Edge）と macOS 標準の Perl** だけで動きます。骨格認識のライブラリとモデル（MediaPipe Pose）と読み上げ音声は同梱です。
- **4つのレベル・全101問**：やさしい／ふつう／むずかしい／エキスパート。10問をランダムに出題します。
- **記録は PC のフォルダに保存**：設定で選んだフォルダの `records.csv` に1回ごとに書き足し、起動時にそこから本日のランキングと人数を読み込みます。

## 0. いちばん簡単な遊び方（インストール不要）
**https://takuden-formula.github.io/ev-quiz/** を Chrome（または Edge・Safari）で開いてカメラを許可するだけ。Windows・Mac・iPad で同じ。
- 読み上げは最初に一度画面をクリック（またはキーを押す）と鳴ります。
- インターネットが無い会場では下の「1. 起動」（フォルダから起動）を使います。
- 中身は GitHub の公開リポジトリ Takuden-Formula/ev-quiz です。直したら push すると 1〜2 分で Web 版に反映されます。

## 1. 起動
1. フォルダを置く（OneDrive に置くときは、フォルダを右クリック →「常にこのデバイスに保持」。音声ファイルがその場でダウンロードされて遅れるのを防ぐ）
2. **`起動.bat` をダブルクリック** → カメラを「許可」
3. 本番は **`起動_全画面.bat`**：アドレスバーなしの窓で開き、**最初に画面をクリック（またはキーを押す）と全画面**になります
   - **Esc で全画面解除**、F キーでもう一度全画面
   - 終了はブラウザの窓を閉じてから、黒い窓を閉じる

> `index.html` を直接開いても動きません。必ず `.bat`（Mac は `.command`）から起動してください。

- ブラウザは **Edge**（無ければ Chrome）を、このゲーム専用のプロファイルで開きます（自動再生を許可して読み上げが最初から鳴るように。前の版の `起動.bat` と同じプロファイルなので、これまでの最高とカメラの許可はそのまま残ります）。
- アドレスは `http://127.0.0.1:8791/`（8791 が使われていれば 8792〜8799）。すでに起動中なら、同じアドレスでブラウザだけ開きます。

### Mac で使う
**いちばん簡単な入れ方（おすすめ）**：**ターミナル**（Launchpad で「ターミナル」と検索）を開き、次の 1 行を貼って return。デスクトップに `ev-quiz` フォルダができて Finder で開きます。この入れ方だと下の「開発元を検証できません」の警告も出ません。
```
curl -fsSL https://raw.githubusercontent.com/Takuden-Formula/ev-quiz/main/mac/install.sh | bash
```
同じ 1 行で最新版に入れ直せます（前の版は `ev-quiz_old_日時` に残ります）。

**ブラウザでダウンロードするとき**：https://github.com/Takuden-Formula/ev-quiz/archive/refs/heads/main.zip を開くと ZIP が落ちてきます。ダブルクリックで展開すると `ev-quiz-main` フォルダが出てきます。

1. 出てきたフォルダを好きな場所（デスクトップや書類）に置く
2. **`起動_Mac.command` をダブルクリック**（本番は **`起動_全画面_Mac.command`**）。ターミナルの窓が開き、Chrome でゲームが開きます
   - **ブラウザでダウンロードした場合、初回に「開発元を検証できないため開けません」と出たとき**：「完了」を押してから、**システム設定 → プライバシーとセキュリティ** を開き、下の方の「“起動_Mac.command”は…」の横の **「このまま開く」** を押す（パスワードを聞かれたら入力）。次からはダブルクリックで開きます
   - それでも開けないときは、**ターミナル**を開き、`bash ` と入力（最後に空白）→ `起動_Mac.command` を窓にドラッグ → return
3. カメラを「許可」。**初回は macOS が「“Google Chrome”がカメラへのアクセスを求めています」と聞く**ので「許可」。断ってしまったら **システム設定 → プライバシーとセキュリティ → カメラ** で Google Chrome を ON にして、Chrome を開き直す
4. 終了は Chrome の窓を閉じてから、ターミナルの窓を閉じる（「プロセスを終了しますか」は「終了」）

| ブラウザ | ゲーム | 読み上げ | 記録フォルダ（records.csv） |
|---|---|---|---|
| Chrome / Edge（推奨） | ○ | ○ | ○ |
| Safari（Chrome が無いとき） | ○（16.4 以上） | 最初に一度クリックかキー操作が必要 | ブラウザ内に保存。設定の「CSV を書き出す」で書き出せる |

- `.command` は Chrome → Edge → Safari の順に探して開きます。サーバは macOS に必ず入っている Perl を使います（Python や Homebrew は不要）
- `.command` ファイルを Windows で編集するときは、改行を LF のままにする（CRLF になると Mac で動かない）

## 2. 遊び方（受付からの流れ）
```
待機（レベル選択・本日のランキング・見どころ）→ レベルのカードに手を1秒かざす → 10問（読み上げ → ポーズで回答 → 正解と解説）
  → 結果（得点・評価・本日の何位か）→ 20秒で待機に戻る
```
1. 挑戦する人はカメラから **1.5〜2.5m** 離れて立つ（**頭の上の手まで含めて上半身が映る**位置）。床にテープで立ち位置を貼っておくと楽です。人が複数映ると、いちばん大きく映る1人が対象です
2. レベル（やさしい／ふつう／むずかしい／エキスパート）のカードに**手を1秒かざす**と開始（クリック・タップ、`1`〜`4` キー、`Enter`＝前回のレベル でも開始）
3. 問題が読み上げられたら、ポーズを**約1秒キープ**して回答
   - **○** = 両手を頭の上で輪にする（手首をくっつけても、指先だけ合わせても、頭に手をのせても OK）
   - **×** = 両腕を胸の前でクロスする（手首のあたりで交差させても、大きくクロスしても OK）
   - 惜しいときは画面下に「○まであと少し → 両手をもっと近づける」などの案内が出ます
4. 1問 20 秒（むずかしい 18 秒、エキスパート 12 秒。設定で変えられる）。問題の読み上げ中は時間が止まり、残り 5 秒からカウントダウンの音が鳴ります
5. 回答すると正解と解説を表示して読み上げ。手をかざす（Space・Enter でも）か、表示から 6 秒たって読み上げが終わったら次の問題へ
6. 10 問で結果。**得点・評価（EVマスター！など）・本日のランキングで何位か・このレベルのこれまでの最高**を出し、記録に 1 行足します。20 秒（設定で変更）たつと待機画面に戻ります
7. 途中で人がいなくなったら（カメラに人が映らず操作も無い状態が 60 秒）、または **3 問続けて時間切れ**のときは、待機画面に戻ります（このときは記録しません）

待機画面には **本日のランキング（上位 5 人：正解数・レベル・回答時間）** と **レベルごとのこれまでの最高**、ポーズのやり方と例題を自動で切り替えて見せる **見どころ** が出ます。

### 読み上げ
- 声は **AI音声（Microsoft Nanami／Keita）の音声ファイル**（`audio/`）を再生します。`V` キー（または設定）で 女性 → 男性 → ブラウザ内蔵音声 を切り替え（選んだ声は保存）。ON/OFF は右上のボタンか `M` キー
- 音声ファイルが無い文は、ブラウザ内蔵の音声で代わりに読みます（Mac では Kyoko など。「拡張」「プレミアム」版を入れてあればそれを優先）
- 問題・解説を変えたとき、または読み方（`speech.js` の `READ`）を直したときは、`音声生成\生成.bat`（Mac は `音声生成/生成.command`）を実行して音声を作り直します（`pip install edge-tts` と Node.js が必要。インターネットが必要で、済んだ文は飛ばす）

## 3. 設定（S キー、または右上の ⚙）
タッチ端末では ⚙ を **1 秒長押し** で開きます（お客さんが触っても開かないように）。設定はブラウザ（localStorage）に保存されます。

| 項目 | 内容 | 初期値 |
|---|---|---|
| 放置で待機画面に戻るまで | カメラに人が映らず操作も無い時間がこれだけ続くと待機画面へ（15〜600 秒） | 60 秒 |
| 結果画面から待機画面に戻るまで | 結果を見せる時間 | 20 秒 |
| 制限時間 | 1 問あたりの秒数（レベルごと） | やさしい 20・ふつう 20・むずかしい 18・エキスパート 12 秒 |
| 効果音 | 正解・不正解・開始・カウントダウン・結果発表（WebAudio で合成）の ON/OFF | ON |
| 効果音の音量 | 0〜100% | 60% |
| 読み上げ | 問題・解説の読み上げの ON/OFF（`M` キーと同じ） | ON |
| 読み上げの声 | AI音声 女性（Nanami）／男性（Keita）／ブラウザ内蔵（`V` キーと同じ） | 女性 |
| **記録を保存するフォルダ** | 「フォルダを選ぶ」で PC のフォルダを選ぶ（下の「記録」）。「CSV を書き出す」で records.csv をダウンロード | 未設定 |
| 集計のリセット | 本日の人数とランキングを 0 から数え直す（records.csv とこれまでの最高は消えない） | – |

### 記録（records.csv）
設定の「記録を保存するフォルダ」で選んだフォルダに `records.csv` を作り、10 問を最後まで遊ぶごとに 1 行足します（Excel で開けます）。

| 列 | 内容 |
|---|---|
| 日時 | 結果が出た日時（例 `2026-11-01 10:23:45`） |
| 受付番号 | その日の何人目か（1, 2, 3…。集計をリセットしても振り直さない） |
| レベル | やさしい／ふつう／むずかしい／エキスパート |
| 正解数・問題数 | 例 7 と 10 |
| かかった時間 | 各問題で答えるまでにかかった秒数の合計（読み上げ中と解説の時間は含まない。時間切れはその問題の制限時間） |

- 起動時にこのファイルを読み、**本日のランキング・挑戦人数**と**これまでの最高**を出します。別の PC で記録したファイルをこのフォルダに置けば、そのまま引き継げます
- ランキングの順は **正解数が多い → レベルが難しい → かかった時間が短い**
- フォルダの場所はブラウザが覚えています。ブラウザを開き直すと、**最初に画面をクリックしたとき「このフォルダの編集を許可しますか」と聞かれるので「許可」**を押してください（画面左下に `記録: 許可待ち` と出ている間はブラウザの中にだけ残ります）
- フォルダを選ばなくても遊べます（そのときの記録はブラウザの中だけに残り、ランキングも出ます。「CSV を書き出す」でダウンロードできます）
- 画面左下に `記録: OK（フォルダ名）／許可待ち／未設定 ・ 本日 ○ 人` を出しています

### キー操作
| キー | 動作 |
|---|---|
| `1`〜`4` | レベルを選んで開始（1 = やさしい … 4 = エキスパート） |
| **Enter** | 待機画面で前回のレベルで開始／正解表示で次へ／結果で待機画面へ |
| `O` / `X` | ○ / × で回答（カメラ不調時の予備） |
| Space | 正解表示で次へ／結果で待機画面へ |
| `R` | 結果で「もう一度」（同じレベル） |
| `M` | 読み上げ ON/OFF |
| `V` | 読み上げの声の切り替え |
| `S` | 設定 |
| `F` | 全画面にする |
| `D` | 判定のようす（スタッフ用。判定結果・理由・手首/指先の距離・肩からの高さを右上に出す） |
| **Esc** | 遊んでいる途中でやめて待機画面へ（全画面のときは**全画面を解除**） |

## 4. 困ったとき
| 症状 | 対処 |
|---|---|
| ポーズが判定されない | 少し下がって、**頭の上の手まで**映るようにする。明るい場所で、背景に人が少ないほど安定する。`D` キーで判定の理由（「手首が見えない」「両肩が映っていない」など）が出るので、それを見て立ち位置を直す |
| 「AIモデルを読み込めません」 | `lib/mediapipe_pose/` が欠けていないか確認（ZIP を全部展開する）。キー操作（`O`/`X`）でも遊べます |
| 「カメラが使えません」 | ほかのアプリ（Zoom・Teams など）がカメラを使っていないか確認。Mac は システム設定 → プライバシーとセキュリティ → カメラ でブラウザを ON |
| 読み上げ・効果音が鳴らない | 画面を1回クリックするかキーを押す。Safari は「Safari → 設定 → Webサイト → 自動再生」で 127.0.0.1 を「すべてを自動再生」にすると最初から鳴る |
| 記録が保存されない | 画面左下が `記録: 許可待ち` なら画面を1回クリックして「許可」。`記録: 未設定` なら設定でフォルダを選ぶ |
| 途中で待機画面に戻ってしまう | 設定の「放置で待機画面に戻るまで」を長くする。カメラに体（両肩）が映っているか確認 |
| これまでの最高が消えた | 起動ファイル以外（別のブラウザ・別のアドレス）で開いていないか確認。最高はブラウザとアドレス（`127.0.0.1:8791`）ごとに保存されます |
| 黒い窓がすぐ閉じる・起動しない | `server_log.txt` を見る。8791〜8799 がすべて使われていると起動できません |

### ポーズ判定のしくみ（`classifyInfo()`）
長さはすべて肩幅を 1 として見るので、カメラからの距離が変わっても同じ基準で判定します。
- **○**：両手首が鼻より上（顔が腕で隠れたら肩から頭の高さを推定。手を頭にのせる形は、肩より 0.45 上＋ひじが上がっていれば可）で、頭の真上付近にあり、**手首どうしが 1.15 以内か、指先どうしが 0.75 以内**
- **×**：両手が胸の高さ（肩の 0.7 上〜1.3 下）にあり、ひじが曲がっていて（腕を下ろしただけは除く）、次のどれか
  - 左右の手首が体の中心をはさんで入れ替わっている
  - ひじ→手先の線（前腕）どうしが交わる
  - 両手が体の中心に寄り、どちらもひじより内側（交差すると AI が左右の手首を取り違えることがあるため）
- 保持中に判定が一瞬外れても 0.35 秒（`GRACE_MS`）は数え続けます
- 確認は `node tests/pose_test.js`（作ったポーズ 15 種 × 左右反転と、ゆらぎを加えた 400 回ずつ）

調整値は `index.html` 冒頭の `HOLD_MS`（ポーズを保持する時間）`GRACE_MS`（判定が一瞬外れても続ける時間）`REVEAL_MS`（正解表示の自動送り）`DWELL_MS`（手をかざす時間）`MISS_LIMIT`（続けて時間切れで戻る回数）。
