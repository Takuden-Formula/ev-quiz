# EVクイズ（○×ボディ判定）

電気自動車に関する○×クイズを、カメラに映った体のポーズで答えるシステム。

## Web 版（インストール不要）
https://salt6004.github.io/ev-quiz/ を開くだけで遊べる（Windows・Mac・iPad など。Chrome / Edge / Safari）。カメラを許可し、読み上げは最初に一度画面をクリックすると鳴る。
- 中身は GitHub の公開リポジトリ salt6004/ev-quiz（URL を知っていれば誰でも見られる）。
- このフォルダを直しても Web 版は変わらない。直したら、リポジトリに同じファイルを上書きして push する（1〜2分で反映）。

## 遊び方
1. Windows は `起動.bat`、Mac は `起動.command` をダブルクリック（Python 3 が必要。ブラウザが開く）。カメラを許可する。開けないときは下の「Mac で使うとき」を見る。
2. レベル（やさしい／ふつう／むずかしい／エキスパート）のカードに**手を1秒かざす**と開始。
3. 出題されたら、ポーズを**約1.2秒キープ**して回答。
   - **○** = 両手を頭の上でくっつける（輪をつくる）
   - **×** = 両腕を胸の前でクロスする
4. 1問20秒（むずかしい18秒、エキスパート12秒）。問題の読み上げ中は時間が止まる。回答後に正解と詳しい解説を表示し、手をかざすか読み上げ終了後6秒で次へ。10問で結果表示（ベストはブラウザに保存）。

読み上げ: 問題と、正解・解説を音声で読み上げる（右上のボタンか `M` キーでON/OFF）。
- 声は **AI音声（Microsoft Nanami／Keita）の音声ファイル**（`audio/`）を再生する。`V` キーで 女性 → 男性 → ブラウザ内蔵音声 を切り替え（選んだ声は保存）。
- 問題・解説を変えたとき、または読み方（`speech.js` の `READ`）を直したときは、`音声生成\生成.bat`（Mac は `音声生成/生成.command`）を実行して音声を作り直す（`pip install edge-tts` と Node.js が必要。インターネットが必要で、済んだ文は飛ばす）。
- 音声ファイルが無い文は、ブラウザ内蔵の音声で代わりに読む（Mac では Kyoko などの声。「拡張」「プレミアム」版を入れてあればそれを優先）。
- ブラウザの仕様で、音が出ないときは一度画面をクリックするかキーを押す（起動ファイルは専用プロファイルのブラウザで開き、自動再生を許可する。Windows は Edge、Mac は Chrome → Edge → 既定のブラウザの順。それでも出ないときはクリック）。
途中でやめたいときは `ESC`（レベル選択に戻る）。読み上げが終わってから次へ進む。

予備のキー操作: `1/2/3/4`=レベル、`O`/`X`=回答、`Space`=次へ、結果画面で `R`=もう一度（`Space`=レベル選択）。
起動ファイルの黒いウィンドウ（Mac はターミナルのウィンドウ）を閉じるとサーバーも止まる（遊び終わるまで閉じない）。

## Mac で使うとき
ダブルクリックで開けないとき（OneDrive 経由だと実行の許可が付かないことが多い）は、ターミナルで起動する。`cd ` のあとに EVクイズ フォルダをドラッグ＆ドロップすると場所が入る。
```bash
cd EVクイズフォルダの場所
bash 起動.command
```
ダブルクリックで開けるようにするには、同じ場所で次を1回実行する（Windows 側でファイルを直すと外れるので、そのときはやり直す）。
```bash
chmod +x 起動.command 音声生成/生成.command
xattr -d com.apple.quarantine 起動.command 音声生成/生成.command 2>/dev/null
```
- 「開発元が未確認のため開けません」と出たら、上の `xattr` を実行するか、「システム設定 → プライバシーとセキュリティ」の「このまま開く」を押す。
- Python 3：入っていなければ、ターミナルで `python3` と打つと出るインストールの案内に従う（または python.org から入れる）。
- ブラウザ：Chrome があれば Chrome、無ければ Edge、どちらも無ければ既定のブラウザ（多くは Safari）で開く。Safari は 16.4 以上（macOS を更新）。Safari では読み上げが自動で鳴らないので、「Safari → 設定 → Webサイト → 自動再生」で 127.0.0.1 を「すべてを自動再生」にする（または最初に一度画面をクリックかキーを押す。以後は鳴る）。
- OneDrive：EVクイズ フォルダを右クリック →「常にこのデバイスに保持」にしておく（音声ファイルがその場でダウンロードされて遅れたり、オフラインで鳴らなかったりするのを防ぐ）。
- カメラ：初回にブラウザがカメラの許可を聞く。出ないときは「システム設定 → プライバシーとセキュリティ → カメラ」で使うブラウザをオンにする。
- 音声生成をするときは edge-tts と Node.js が必要。`bash 音声生成/生成.command` を実行すると、足りないものと入れ方を表示する。
- `.command` ファイルを Windows で編集するときは、改行を LF のままにする（CRLF になると Mac で動かない）。

## 構成
- `index.html` … 本体。MediaPipe Pose（CDN）で骨格を推定、`classify()` でポーズ判定。
- `speech.js` … 読み上げ用の読み替え辞書 `READ` と、文の分割・音声ファイル名の計算。
- `audio/` … 事前に作った読み上げ音声（`nanami/` `keita/`）。`音声生成/` … 作り直しツール。
- `questions.js` … 問題データ（全101問：やさしい24・ふつう25・むずかしい25・エキスパート27。10問をランダム出題）。追加は `{q, a:'O'|'X', e}` を足すだけ。解説は最初の1文を「なぜその答えか」にする。
- 調整値は `index.html` 冒頭の `HOLD_MS` `Q_SECS`（レベル別の制限時間）`REVEAL_MS` `DWELL_MS`。

## 注意
- 初回はインターネット接続が必要（MediaPipe を CDN から読み込む）。
- カメラに頭の上の手まで含めて上半身が入る位置、1.5〜2.5m 離れて立つ。人が複数いると1人（最も大きく映る人）が対象。
- 明るい場所で、背景に人が少ないほど安定する。
